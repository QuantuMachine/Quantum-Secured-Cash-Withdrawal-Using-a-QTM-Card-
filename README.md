# Quantum-Secured Cash Withdrawal Using a 'QTM Card'

This project demonstrates how traditional banking authentication and cash withdrawal systems can be enhanced using quantum computing concepts such as qubits, quantum gates, and secured verification protocols.

This course is available on Udemy and is associated with the QuantuMachine educational project.

## Overview

Today’s banking systems mainly rely on classical cryptographic methods to protect transactions, user identity, and financial data. However, with the rapid advancement of quantum computing, many classical security techniques may become vulnerable in the future.

This project explores how a **hybrid classical–quantum banking system** can be designed and simulated to improve transaction security. The central idea is to model a quantum-secured cash withdrawal process using a QTM card, where quantum states and circuit-based verification help strengthen authentication.

The repository is designed as an educational and research-oriented resource for learners interested in quantum computing, cryptography, and real-world applications of quantum algorithms.

---

## Objectives

- Understand the role of quantum computing in secure banking systems
- Learn how qubits and quantum gates can be used for authentication
- Simulate a quantum-secured cash withdrawal workflow
- Explore hybrid classical–quantum security models
- Implement and validate quantum circuits using Python and Qiskit
- Provide a practical learning resource for students and researchers
